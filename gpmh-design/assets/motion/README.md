# Escultura GPMH — código reutilizável

Motor, CSS, poster e atribuição da versão1.3.0-rc1, sem fonte comercial incorporada. O módulo lê posição, escala, transformação, expansão, opacidade e drift pelos atributos do elemento e eventos descritos no guia do kit.

A integração completa, exemplos e API documentada estão em `../brand-kit/modules/BRAIN-SCULPTURE.md` e `../brand-kit/modules/demo.html` quando o kit é anexado. Estes arquivos são a camada de renderização; não substituem o HTML/CSS/controle da página, nem desenham tipografia ou logo.
